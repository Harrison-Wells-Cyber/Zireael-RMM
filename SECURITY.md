# Security Policy

I want this to be a tool real practitioners can feel comfortable using on real engagements. As such, security is important and will be taken seriously. I would encourage any users to audit this project and report vulnerabilities, especially anything that could lead to inadvertent disclosure of client data. If you discover a vulnerability in this project, please use the GitHub reporting function, or email henrylevercyber@gmail.com. I will respond to you and address the issue as soon as possible.
